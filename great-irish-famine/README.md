# The Great Irish Famine: an economic history

A static lecture microsite based on Chris Colvin’s ECO3020 lecture at Queen’s University Belfast.

## Publish with GitHub Pages

1. Put the contents of this archive in the root of a GitHub repository.
2. In Settings → Pages, select Deploy from a branch.
3. Select main and / (root), then save.

On GitHub Free, use a public repository.

No build or installation is needed. Keep the assets folder beside index.html. Relative links support both a project site and a custom domain.

## Edit

- index.html: text and links
- styles.css: appearance
- site.js: figure viewer and chapter highlighting
- assets/: figures and downloadable lecture

The lecture and figures retain their original attribution. No blanket licence is granted to third-party material.
